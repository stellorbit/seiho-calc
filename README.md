# 生活保護費シミュレーター (seiho-calc)
<!-- push verification: 2026-11-04 -->

> **生成AI利用クレジット**
> - **計画書作成**: Gemini 4 Argon
> - **サイト作成**: Gemini 3.8 Flash

令和8年（2026年）10月1日施行 改正生活保護基準（令和8年厚生労働省告示第245号準拠）に対応した、生活保護費（生活扶助＋住宅扶助＋各種加算）の受給見込額シミュレーターです。

## 特徴

1. **完全クライアントサイド演算（Zero-Data Retention）**:
   - 入力された世帯状況や障害手帳等のデータはブラウザ内メモリでのみ処理され、外部サーバーへの送信・保存は一切行われません。
2. **高精度なドメインロジック**:
   - 級地（1-1〜3-2）、世帯員別第1類、世帯人数別逓減率、第2類、10円未満切り上げ端数処理。
   - 臨時特例加算（在宅2,500円/人）、経過的加算、従前額保障基準額との自動比較判定。
   - 児童養育加算（18歳以下 10,190円/人）、母子加算、障害者加算（区分A/B）、冬季加算（Ⅰ〜Ⅵ区参考値）。
3. **全国47都道府県の市町村詳細展開**:
   - 級地区分表に掲げられた市町村（1級地-1〜3級地-1）と「上記以外の市町村（3級地-2）」を都道府県別JSONとして整備し、都道府県選択時にオンデマンドで取得。
   - 住宅扶助（家賃・間代等）の限度額は世帯人員別（1人／2人／3〜5人／6人／7人以上）。指定都市・中核市は市ごとの額、それ以外は都道府県×級地（1・2・3級地）の額を適用。
4. **共益費・管理費の実務ルール対応**:
   - 原則（別払い契約：共益費は生活費自己負担）および例外（共益費込契約：基準内住宅扶助算入）に対応。
   - 支給総額だけでなく、「手元に残る実質生活費（可処分額）」を算出して可視化。
5. **超軽量・アクセシブルなUI**:
   - Astro (Static Output) + Vanilla TypeScript（クライアントJSペイロード 約18KB）。
   - BIZ UDPゴシック（UDフォント）、WCAG AAA準拠コントラスト比、320px〜完全レスポンシブ。

## ローカル実行

```bash
# 依存関係のインストール（pnpm推奨）
pnpm install

# 自治体マスターデータの生成
node scripts/generate_municipalities.js

# スキーマ検証および単体テスト
pnpm test

# 開発サーバー起動
pnpm run dev

# 静的ビルド
pnpm run build

# ビルド成果物のプレビュー
pnpm run preview
```

## 住宅扶助・級地データの出典

自治体マスター（`public/data/municipalities/*.json`）は `scripts/generate_municipalities.js` が次の2つのデータから生成します。

| データ | ファイル | 出典・基準日 |
| :--- | :--- | :--- |
| 級地区分 | `scripts/data/kyuchi_h30.json` | 厚生労働省「級地区分（市町村別）」平成30年10月1日現在（<https://www.mhlw.go.jp/content/kyuchi.3010.pdf>） |
| 住宅扶助限度額 | `scripts/data/housing_limits_r8.json` | 平成27年4月14日社援発0414第9号に基づく世帯人員別限度額。令和3年4月現在の一覧（非公式転載: <http://kobekoubora.life.coocan.jp/2021juutakufujo.pdf>）を令和8年10月現在の額として採用 |

- 令和2年4月現在の一覧との差分は、令和3年4月に中核市へ移行した松本市・一宮市の追加のみです。令和4年度以降、限度額の改正および新たな中核市移行は確認されていません。
- 名古屋市の1人・2人・3人世帯の限度額（37,000円・44,000円・48,000円）は、名古屋市公式資料「令和7年度（令和7年10月以降）の最低生活費（モデル世帯）」と一致することを確認済みです。それ以外の自治体の額は公式資料との個別照合を行っていません。
- 単身世帯の床面積別限度額（床面積15㎡以下の減額）は未対応です。

## 免責事項

本シミュレーターによる試算結果は、令和8年厚生労働省告示第245号（改正生活保護基準）に基づく概算試算値です。実際の生活保護費の受給可否および支給決定額は、お住まいの自治体を管轄する福祉事務所（生活援護課等）による調査・認定によって最終決定されます。
